# Scan to Flow · landing site

Landing page, **Privacy Policy** and **Terms of Use** for the Scan to Flow app (iOS & Android), in English and Vietnamese. Static HTML generated by a tiny Node script and styled with Tailwind CSS v4. Hosted on GitHub Pages.

Use the Privacy and Terms URLs in the app's paywall, App Store Connect (app privacy + subscriptions) and Play Console.

## Develop

```sh
npm ci
npm run dev        # builds, then serves http://localhost:4173/scan-to-flow-landing/
npm run watch:css  # optional, in a second terminal while editing classes
npm run check      # every internal link in dist/ resolves
```

`npm run build` = `build:html` (renders pages to `dist/`) + `build:css` (Tailwind, minified).

## Where things live

| What | File |
|---|---|
| Site URL, store links, developer, email, legal dates | `site.config.mjs` |
| `<head>`, SEO/OG/hreflang, footer, logo mark | `src/layout.mjs` |
| Landing page + EN/VI copy | `src/pages/home.mjs` |
| Legal page template, 404 | `src/pages/legal.mjs` |
| Privacy Policy text (EN/VI) | `src/content/privacy.mjs` |
| Terms of Use text (EN/VI) | `src/content/terms.mjs` |
| Tailwind theme (brand tokens), custom CSS | `src/styles.css` |
| Self-hosted fonts (Be Vietnam Pro, JetBrains Mono) | `public/fonts/`, `src/fonts.css` |
| Screenshots, icons, OG image, JS | `public/` |

When the app's data collection changes, update `src/content/privacy.mjs` and `legalUpdated` in `site.config.mjs` in the same release as the store privacy labels.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds, checks links and publishes `dist/` to GitHub Pages.

One-time setup: **Settings › Pages › Build and deployment › Source: GitHub Actions**.

Custom domain later: set `SITE_URL` in `site.config.mjs` (e.g. `https://scantoflow.app/`), add a `public/CNAME` file containing the domain, and configure the domain in Settings › Pages.
